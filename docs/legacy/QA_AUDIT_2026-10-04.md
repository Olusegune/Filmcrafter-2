# QA audit, 4 October 2026 (version 1.11.2 plus fixes)

What was checked, what was found, what was fixed, and what is still unproven.

## How it was checked

| Layer | Method | Result |
|---|---|---|
| Python engine | Static scan (ruff: undefined names, unsafe calls, shell use, eval, pickle, mutable defaults) | No defects. Only style notes. |
| Python engine | Crash test: every command of every module run with empty, wrongly typed and garbage input | No unhandled crash except malformed JSON, which the app never sends (now reported as one readable line) |
| Python engine | Coverage run (75 % of lines) and new tests for the weakest important modules | `review.py` 0 % to tested on real video files; `concepts.py`, `command.py` tested; whole Create from song path tested in one run |
| Video models | Request built offline for every Kie video model and 50 fal models and checked against each model's own rules | All 60 readable Kie generators and 48 of 50 fal models pass; the other two need an end frame you choose, and say so |

| Interface | Search for unhandled promise failures, innerHTML, eval | 2 minor flaws found and fixed |
| Rust shell | `cargo clippy` and a search for panics | Clean (one style warning); the only unwraps are on locks and on pipes just created |
| Layers agree | Rust action lists against the engine's own action lists (13 commands) | No mismatches |
| Dependencies | `npm audit` | 0 known vulnerabilities |
| Secrets | `rafter secrets` | Clean |
| Real project | Read-only integrity check of "The Family Circus ... vs 4" (43 shots, 53 jobs, 42 library items) | Healthy; one real problem found (below) |

| Packaging | Installed engine folder compared with the source | Every engine file ships |

## Problems found and fixed

1. **Black first 4.5 seconds, with no warning.** In the real project the first shot starts at 0:04.5 (the song's intro has no shot), so the export shows black there. The Supervisor now lists every uncovered stretch of a second or more ("Black stretch in the film: 0:00.0 to 0:04.5") with the nearest shot and a fix.
2. **An empty plan was written without explanation** when a song had no sections. The treatment now stops with "The song has no sections yet…".
3. **Unexpected engine crashes showed raw Python lines with file paths.** Any uncaught engine error is now one readable message; the full trace stays in the log.
4. **Continuity sheet:** the "continuous" checkbox ignored a failed save silently; it now reloads to show the true state.
5. **Lyrics step:** a failed project load could leave the step blank; it now opens with empty lyrics.

(Earlier in the same session: video models sent the cast sheet as a last frame, Happy Horse's misspelled field, Grok's 5,000-character limit, the whole Seedance 2 family's first-frame rule, Kling 3 Turbo's single picture, the audio clip uploaded as a picture, the fal price shown as $103,680, the voiced line missing from prompts, and lyric lines assigned to the wrong shot. See the changelog.)

## Not covered, and why

- **Real paid renders.** Nothing here sends a render, so a model can pass every request check and still produce a poor or empty video. Each new model deserves one 4-second test.
- **The native Windows window.** The interface was checked in a test harness, not the packaged app. The Settings screen could not be loaded in the harness at all.
- **ComfyUI on a real machine**, native dialogue on a sound-capable model, the Premiere and Resolve import in the actual editors, the update check (the repository is private, so it reports "not available"), Mac builds, and code signing.
- **Two processes saving the same small file at once** (for example project.json written by the app and the engine together) is protected for the render queue (locked and merged) and by unique temp files elsewhere, but not by a lock on every file.
- **Old project files** made by earlier versions were not migrated or re-tested beyond the one real project.
