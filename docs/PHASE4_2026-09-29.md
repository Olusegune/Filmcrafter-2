# Phase 4: Routing modes, project budgets, Local Model Manager and offline (29 Sep 2026)

## What was built

- **Plan & budget** (the top-bar chip shows the mode and spend; click it to open the sheet). There are three modes per project:

  | Mode | Behaviour |
  |---|---|
  | Local First | Only this computer: ComfyUI workflows, a local AI brain, moving stills, your own media and export. Paid cloud renders are refused in the engine, so nothing can be spent and everything works offline. |
  | Balanced | Auto uses the cheapest proven models: Wan 3.0 video and Nano Banana stills, on Kie before fal. |
  | Premium | Auto uses the best proven models: Seedance 2 or Veo video, and GPT Image 2.5 stills. It is the default, and matches what PULSEFRAME did before. |

  "Render all", the shot and keyframe panels and Autopilot start from the mode's pick. Any model can still be chosen by hand.
- **Project budget.** A dollar limit per project, with a spent/remaining bar.
  - Every batch is priced before it is queued. If it would go past the budget, it is refused with the numbers and nothing is sent.
  - Kie credits count at $0.005 each. Models with no published price count high ($1 per video, $0.10 per still), so the budget is never under-counted.
  - Automatic keyframe re-makes respect the budget too.
- **Local Model Manager** (Settings → Models on this computer):
  - Ollama: installed models with size and vision ability; *Download* (the recommended list or any model name, with progress), *Remove* (asks first), and *Use* to make a model the AI brain's planner and/or vision model.
  - LM Studio: shows the loaded models, each with a *Use* button.
  - ComfyUI: shows its status, GPU and workflows.
- **Offline.** Online/offline is shown in Plan & budget and on the chip. When offline, a banner says cloud renders will wait and lists what keeps working: own media, moving stills, continuity, acting, export, and the local brain and ComfyUI when set up.

## Evidence

- **Tests:** 131 engine tests pass, 9 of them new. They cover mode picks, Local First refusing cloud but allowing ComfyUI, the budget refusing an over-budget batch, unknown prices counting high, enqueue guarded with nothing queued, budget validation, and the Local Model Manager with nothing running plus unsafe model names being rejected.
- **Installed app:**
  - On BYOM Test with a $0.10 budget, a Wan batch was refused: "has spent $0.00 of its $0.10 budget … would add about $0.35. Nothing was sent."
  - In Local First, a fal render was refused.
  - The job list was unchanged afterwards.
  - The Plan & budget sheet on QA Flow Song showed Balanced routing to Wan 3.0 and Nano Banana on Kie, with $0.16 of $10 spent.
  - Settings shows the Local models panel.

## Known limitations

- Ollama and LM Studio aren't installed on this PC, so a real model download wasn't run. The code follows Ollama's documented pull API, and the not-running path was tested.
- Offline mode wasn't tested by unplugging the network; the detection is covered by a unit test.
- The budget covers render spend. OpenAI brain calls (plans, checks) are small and are not counted against it.

## Gate

Modes, budgets and the local manager work in the installed app. Nothing can be spent in Local First or past a budget.
